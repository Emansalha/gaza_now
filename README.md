## 📰 الأخبار الحقيقية (جديد في 1.2)

يقرأ التطبيق الموجزات الرسمية (RSS) مباشرة من 10 مصادر، ويدمجها مع API التطبيق الذي يجلب صورة لكل خبر:

| المصدر | النوع |
|---|---|
| الجزيرة نت | شبكة إخبارية عربية |
| أخبار الأمم المتحدة | الخدمة الرسمية للأمم المتحدة |
| بي بي سي عربي | هيئة الإذاعة البريطانية |
| فرانس 24 | الشرق الأوسط |
| الأناضول | وكالة أنباء دولية |
| سكاي نيوز عربية | قناة إخبارية |
| DW عربية | دويتشه فيله |
| عرب 48 | موقع فلسطيني |
| القدس العربي | صحيفة يومية |
| CNN بالعربية | الشرق الأوسط |

- كل خبر يظهر **باسم مصدره ووقته وصورته** وزر «اقرأ الخبر كاملاً» يفتح المصدر الأصلي.
- تبويب «غزة وفلسطين» يفرز الأخبار تلقائياً، و«كل الأخبار» يعرض الكل.
- شريط عاجل متحرك، وعرض صور متحرك (Carousel) لأهم الأخبار، وانتقال الصورة بحركة Hero إلى صفحة الخبر.
- خريطة تفاعلية لمحافظات القطاع الخمس مع عدد الأخبار الحالية لكل محافظة.
- بحث في كل المصادر، حفظ الأخبار للقراءة بدون إنترنت، ومشاركة الخبر.
- اختيار المصادر من «المزيد ← مصادر الأخبار».
- يعمل بدون إنترنت بآخر نسخة محفوظة.

## 🔴 بث المراسلين المباشر (جديد في 1.5)
الصحفي يسجّل (الاسم، المؤسسة، الهاتف، البطاقة، منطقة التغطية، نبذة)، ثم يضغط 🎥 في القناة:
يبدأ البث من YouTube / Facebook / TikTok / Instagram ويلصق الرابط، فيظهر للمشتركين شريط أحمر «مباشر الآن» وبطاقة «شاهد البث»، ويستطيع إنهاء البث بزر واحد.

## ✨ مزايا أخرى

- **شاشة افتتاحية متحركة**: شعار «Breaking News Live» يدور حول نفسه (وهو أيضاً أيقونة التطبيق وشاشة إقلاع أندرويد).
- **شاشة افتتاحية متحركة (تفاصيل)**: يظهر الشعار بحركة ارتداد ناعمة، تنبض حوله موجات بث، ويُعزف لحن أخبار قصير (`assets/sounds/news_intro.mp3`). اضغط على الشاشة للتخطي.
- **قناة المراسلين (مثل تيليجرام)**:
  - القرّاء يشتركون في القناة ويمكنهم كتم الإشعارات أو تفعيلها.
  - الصحفيون يسجّلون (الاسم، المؤسسة، الهاتف، البطاقة الصحفية + ميثاق النشر) ثم ينشرون الأخبار فوراً.
  - لكل منشور: المنطقة، وسم «عاجل»، اسم الصحفي، علامة «موثّق» أو «بانتظار التوثيق»، عدد المشاهدات والوقت.
  - أحدث الأخبار في الأسفل مثل تيليجرام، مع شارة لعدد الأخبار الجديدة وتنبيه داخل التطبيق للأخبار العاجلة.
  - ضغطة مطوّلة على المنشور: نسخ النص، أو حذفه إن كان من منشوراتك.
- واجهة عربية كاملة من اليمين لليسار في جميع الشاشات، بخط Cairo.
- وضع داكن يُحفظ بين الجلسات.
- تصفية الأخبار حسب المحافظة، بحث يفتح الخبر، حفظ الأخبار بشكل دائم.
- إشعارات قابلة للتصفية (الكل / غير مقروء / عاجل).
- أيقونة التطبيق وشاشة الإقلاع الأصلية جاهزتان للتوليد.

## 🚀 التشغيل

```bash
git clone https://github.com/Emansalha/gaza_now
cd gaza_now
flutter pub get
flutter run
```

مجلدات Android و iOS موجودة وجاهزة: اسم التطبيق، صلاحية الإنترنت، الإعلانات، التوقيع. يتطلب Flutter 3.32 أو أحدث.

### ⬇️ تحميل مباشر
**https://github.com/Emansalha/gaza_now/releases/latest/download/gaza-now.apk**

### 🔌 API الأخبار الخاص بالتطبيق
كل 30 دقيقة يجمع GitHub Actions الأخبار من المصادر السبعة ويجلب صورة كل خبر، ثم ينشرها كـ JSON على:
`https://raw.githubusercontent.com/Emansalha/gaza_now/data/news.json`

التطبيق يقرأ منه أولاً (طلب واحد سريع، وصور لكل الأخبار)، وإن تعذّر يقرأ موجزات RSS مباشرة.
الكود: `tools/build_feed.py`، والجدولة في `.github/workflows/news-api.yml`.

### تحميل APK / AAB من Actions
كل رفع على `main` يبني التطبيق تلقائياً. افتح **Actions** ← آخر تشغيل ← **Artifacts**:
- `gaza-now-apk` للتثبيت المباشر على الهاتف
- `gaza-now-playstore-aab` للرفع على Google Play

### 💰 الإعلانات (3 مواضع)
1. بانر داخل الرئيسية بعد الخبر الرابع
2. مستطيل أسفل نص كل خبر
3. إعلان ملء الشاشة: مرة كل 5 أخبار وبحد أقصى مرة كل 3 دقائق

تعمل حالياً بمعرّفات Google **التجريبية**. لتفعيل الأرباح راجع **[LAUNCH.md](LAUNCH.md)**.

### 🔌 الأخبار عبر API
إضافة مفتاح NewsData.io (`NEWSDATA_API_KEY`) تضيف أخبار مئات المواقع العربية بالصور. التفاصيل في [LAUNCH.md](LAUNCH.md).

## 🔌 ربط القناة بخادم حقيقي

النسخة الحالية تحفظ منشورات القناة **على الجهاز نفسه** (تعمل بدون إنترنت، مناسبة للعرض والتجربة).
لكي يصل خبر الصحفي إلى **كل المشتركين فوراً** على أجهزتهم يلزم خادم. الكود مُعدّ لذلك:
`ChannelRepository` واجهة مجردة، فيكفي كتابة تنفيذ جديد واستبداله في `main.dart`.

المسار المقترح (Firebase):
1. **Cloud Firestore**: مجموعة `posts`؛ `watchPosts()` = `collection('posts').orderBy('createdAt', descending: true).snapshots()`.
2. **Firebase Auth** (رقم الهاتف) لتسجيل الصحفيين، مع حقل `status` لا يغيّره إلا المحرر.
3. **Security Rules**: النشر مسموح فقط للصحفيين المسجّلين، والتوثيق للإدارة فقط.
4. **Cloud Messaging (FCM)**: موضوع `channel` يشترك فيه القارئ عند الضغط على «اشتراك»، و Cloud Function ترسل إشعاراً عند كل خبر عاجل.
5. لوحة تحرير لمراجعة الصحفيين وتوثيقهم وحذف المخالفات.

## ⚠️ قبل النشر العام

- الأخبار حقيقية من المصادر المذكورة؛ منشورات القناة الأولى فقط **أمثلة توضيحية**.
- عند النشر على المتاجر راجع شروط استخدام موجزات RSS لكل مصدر.
- يلزم: مصادر أخبار موثوقة وآلية تحرير، مزود خرائط حقيقي، مصدر بث مرخّص، سياسة خصوصية، وإدارة صلاحيات.
- لحن الافتتاح مؤلَّف خصيصاً لهذا التطبيق (ليس مقتبساً من أي قناة).
