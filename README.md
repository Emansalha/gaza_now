<h1 align="center">غزة الآن | Gaza Now</h1>

<p align="center">تطبيق Flutter إخباري عربي لمتابعة مستجدات قطاع غزة، مع قناة مراسلين مباشرة على طريقة تيليجرام.</p>

---

## ✨ المزايا

- **شاشة افتتاحية متحركة**: يظهر الشعار بحركة ارتداد ناعمة، تنبض حوله موجات بث، ويُعزف لحن أخبار قصير (`assets/sounds/news_intro.mp3`). اضغط على الشاشة للتخطي.
- **قناة المراسلين (مثل تيليجرام)**:
  - القرّاء يشتركون في القناة ويمكنهم كتم الإشعارات أو تفعيلها.
  - الصحفيون يسجّلون (الاسم، المؤسسة، الهاتف، البطاقة الصحفية + ميثاق النشر) ثم ينشرون الأخبار فوراً.
  - لكل منشور: المنطقة، وسم «عاجل»، اسم الصحفي، علامة «موثّق» أو «بانتظار التوثيق»، عدد المشاهدات والوقت.
  - أحدث الأخبار في الأسفل مثل تيليجرام، مع شارة لعدد الأخبار الجديدة وتنبيه داخل التطبيق للأخبار العاجلة.
  - ضغطة مطوّلة على المنشور: نسخ النص، أو حذفه إن كان من منشوراتك.
- واجهة عربية كاملة من اليمين لليسار في جميع الشاشات، بخط Cairo.
- وضع داكن يُحفظ بين الجلسات.
- تصفية الأخبار حسب المحافظة، بحث يفتح الخبر، حفظ الأخبار بشكل دائم.
- إشعارات قابلة للتصفية (الكل / غير مقروء / عاجل).
- أيقونة التطبيق وشاشة الإقلاع الأصلية جاهزتان للتوليد.

## 🚀 التشغيل

```bash
flutter create . --platforms=android,ios --org ps.gazanow   # مرة واحدة لتوليد مجلدات المنصات
flutter pub get
dart run flutter_launcher_icons          # أيقونة التطبيق
dart run flutter_native_splash:create    # شاشة الإقلاع الأصلية
flutter run
```

يتطلب Flutter 3.27 أو أحدث.

### تحميل APK جاهز
كل رفع على فرع `main` يبني APK تلقائياً عبر GitHub Actions. افتح تبويب **Actions** ← آخر تشغيل ← **gaza-now-apk**.

## 🔌 ربط القناة بخادم حقيقي

النسخة الحالية تحفظ منشورات القناة **على الجهاز نفسه** (تعمل بدون إنترنت، مناسبة للعرض والتجربة).
لكي يصل خبر الصحفي إلى **كل المشتركين فوراً** على أجهزتهم يلزم خادم. الكود مُعدّ لذلك:
`ChannelRepository` واجهة مجردة، فيكفي كتابة تنفيذ جديد واستبداله في `main.dart`.

المسار المقترح (Firebase):
1. **Cloud Firestore**: مجموعة `posts`؛ `watchPosts()` = `collection('posts').orderBy('createdAt', descending: true).snapshots()`.
2. **Firebase Auth** (رقم الهاتف) لتسجيل الصحفيين، مع حقل `status` لا يغيّره إلا المحرر.
3. **Security Rules**: النشر مسموح فقط للصحفيين المسجّلين، والتوثيق للإدارة فقط.
4. **Cloud Messaging (FCM)**: موضوع `channel` يشترك فيه القارئ عند الضغط على «اشتراك»، و Cloud Function ترسل إشعاراً عند كل خبر عاجل.
5. لوحة تحرير لمراجعة الصحفيين وتوثيقهم وحذف المخالفات.

## ⚠️ قبل النشر العام

- الأخبار والإشعارات ومنشورات القناة الأولى **بيانات توضيحية**.
- يلزم: مصادر أخبار موثوقة وآلية تحرير، مزود خرائط حقيقي، مصدر بث مرخّص، سياسة خصوصية، وإدارة صلاحيات.
- لحن الافتتاح مؤلَّف خصيصاً لهذا التطبيق (ليس مقتبساً من أي قناة).
